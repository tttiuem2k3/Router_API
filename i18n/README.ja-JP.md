# Japanese README

This localized README has been reduced to a clean self-hosted summary for publishing your own fork.

## Quick start

```bash
cp .env.example .env
npm install
npm run dev
```

- Dashboard: `http://localhost:20128/dashboard`
- API: `http://localhost:20128/v1`

## Publishing notes

- Replace `https://github.com/<your-account>/<your-repo>` with your repository URL.
- Replace `https://your-domain.example` with your own cloud endpoint.
- Review `LICENSE`, package names, images, and any remaining upstream references before publishing.

See the main documentation in [`../README.md`](../README.md).
