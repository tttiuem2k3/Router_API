# Tai lieu tieng Viet

Day la ban README rut gon cho fork self-hosted.

## Tom tat

- Dashboard local: `http://localhost:20128/dashboard`
- API local: `http://localhost:20128/v1`
- Chay nhanh:

```bash
cp .env.example .env
npm install
npm run dev
```

## Luu y khi dua len GitHub

- Thay cac placeholder nhu `https://github.com/<your-account>/<your-repo>`
- Thay `https://your-domain.example` bang domain cloud cua ban
- Kiem tra lai `LICENSE`, package name, hinh anh, va link upstream con sot
